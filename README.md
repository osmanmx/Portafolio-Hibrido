# Portafolio de Inversión - Híbrido
El siguiente script analiza el rendimiento de 5 criptomonedas y 5 acciones a partir de una matriz conjunta de 10 activos financieros. Se trata de un Portafolio de inversión con posibilidades de obtener un rendimiento anual del 10% en lo que resta del año 2026 (creado con material del Curso <b>Python para Finanzas: Análisis Cuantitativo y Modelado de Datos</b> del <b>Dr. Wellcome Peujio</b> impartido a profesores de la UNAM en junio-julio del 2026). Al correr el Modelo de Markowitz de forma integrada con datos históricos del presente año, el algoritmo utiliza la baja correlación natural entre la renta variable tradicional y los criptoactivos para encontrar las proporciones matemáticas exactas que minimizan el riesgo global del portafolio. Un buen comienzo para diseñar un BOT-Automático de trading con alertas en <i>TradingView</i> y ejecución de operaciones en <i>broker/exchange</i>.
